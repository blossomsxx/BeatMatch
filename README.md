# BeatMatch
An interactive 2D rhythm game built in python.

To play, press the corresponding keys a, s, k, and l and match them with the corresponding targets.
if you hit the corresponding target, your hit counter will go up. If you miss, you miss counter will go up.
to win, get at least 50 hits. You will lose the game if you get more than 30 misses.

This project was originally created in CMU CS Academy and later rebuilt in Visual Studio Code where it was implemented using Python's pygame library.
